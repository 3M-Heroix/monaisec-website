# Security policy

MONAISEC is a static research website hosted on GitHub Pages. It does not currently provide user accounts, server-side APIs, payment processing, or user-submitted data workflows.

## Reporting a website security issue
Do not include secrets, personal data, credentials, or exploit payloads in public issues. Report suspected vulnerabilities privately to the project maintainer using the contact address published on monaisec.com. Include the affected page, impact, reproduction steps at a high level, and a safe contact method. Allow reasonable time for triage before public disclosure.

## Scope and limitations
This policy covers the public static website and repository configuration maintained by the project. It does not establish a vulnerability disclosure program for third-party products, sources, frameworks or financial institutions discussed in MONAISEC research.
