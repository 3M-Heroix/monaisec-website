MONAISEC favicon package
========================

This package uses the exact logo supplied by the project owner, recreated as clean vector geometry from the low-resolution reference.

Files:
- favicon.svg       Vector favicon (preferred)
- favicon.ico       Multi-size browser/legacy fallback
- favicon.png       1024 x 1024 square icon for PNG/mobile fallback
- favicon-1024.png  High-resolution original-aspect raster
- *.html            Updated site pages with favicon references

Install:
1. Extract all files into the root of the GitHub Pages repository.
2. Replace the included HTML pages when prompted.
3. Keep the favicon files in the same root directory as index.html.
4. Commit and push.

No other website assets or datasets are included.
